2. Core Features Execution

1. The "Smart" Input Box No dropdowns. A single, strict input field with regex routing:
  • 2023-ag-10160 triggers Single View.
  • 2023-ag-10100 to 10160 or comma-separated lists trigger Batch View.
  • Saved Sections: Rendered below the input box via browser LocalStorage.
2. Batch Result & Leaderboard Asynchronous data fetching to handle entire class ranges quickly.
  • The Podium: Top 3 Students displayed prominently (Toggle between Overall CGPA and Latest SGPA).
  • Prune & Auto-Update Magic: Every row in the batch table has a "Trash/✖" icon. Clicking it instantly removes the student and recalculates the Class Average and Top 3 podium using React state (Zero page reloads).
  • Save My Section: A "Pin this List" button saves the pruned/cleaned list of AG numbers to LocalStorage for 1-click retrieval in the future.
3. Single Student Dashboard (Transcript Editor) A fully editable, professional transcript view.
  • Add/Delete Subjects: Every semester card has a "+ Add Subject" button. Every subject row has a "Trash/✖" icon. Non-credit subjects can be deleted, and new theoretical subjects can be added. CGPA updates instantly.
  • Graphical Progress Tracker: A clean line graph mapping SGPA trajectory across semesters.
4. Smart CGPA Predictor & Goal Setter Algorithm-driven goal tracking.
  • Smart Distribution: User inputs a goal CGPA. If impossible in one semester, the algorithm distributes the required GPA across the remaining semesters (max 8) realistically.
  • Maintenance Mode: Once the goal is achieved, the system outputs the "Safe Zone" GPA required to maintain it.
5. Head-to-Head Combat (1v1 Comparison) A split-screen view comparing two AG numbers side-by-side. Compares Metrics: Overall CGPA, Latest SGPA, Cleared Credit Hours, and top grades.

3. Accuracy & Logic Protocols (UAF Official Fractional System)

To maintain absolute "0% fault" status, the calculation engine completely avoids flat grade mappings (like A=4, B=3) and instead implements the official UAF continuous fractional mathematical formulas based on exact percentages.

  • Step 1: Calculate Percentage (P)
    P = (Obtained Marks / Total Marks) × 100
  • Step 2: Determine Subject Exact GPA
    Grade A (80% - 100%): GPA = 4.00
    Grade B (65% - 79%): GPA = 3.00 + ((P - 65) / 15)
    Grade C (50% - 64%): GPA = 2.00 + ((P - 50) / 15)
    Grade D (40% - 49%): GPA = 1.00 + ((P - 40) / 10)
    Grade F (< 40%): GPA = 0.00
  • Step 3: Calculate Quality Points (Q.P.)
    Q.P. = Subject Exact GPA × Credit Hours
  • Step 4: Final Calculations
    SGPA = Sum of (All Subject Q.P.) / Total Semester Credit Hours
    CGPA = Sum of (All Earned Q.P.) / Total Cleared Credit Hours
